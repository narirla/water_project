# 🌿 WATER PROJECT
### 낙동강(물금·금곡) 기반 녹조 발생 위험도 예측

---

## 1. 프로젝트 개요

- **주제**: 낙동강 수질 데이터를 기반으로 녹조 위험도 예측 모델 구축  
- **기간**: 2025.12.23 ~ 2026.01.02  
- **인원**: 3명  
- **목적**:  
  녹조 발생 원인을 분석하고 머신러닝 기반 예측 모델을 통해  
  사전 대응 가능한 데이터 기반 의사결정 지원

---

## 2. 데이터

- **출처**
  - 공공데이터포털 (DATA.go.kr)
  - 국립환경과학원 수질 DB
  - 한국수자원공사 방류량 데이터 

- **분석 지점**
  - 금곡, 물금 (낙동강 주요 취수원) 

- **데이터 기간**
  - 2021 ~ 2025 

### 주요 변수

- 수온, DO, BOD, COD  
- T-N, T-P (영양염류)  
- 클로로필-a (녹조 지표)  
- 유량

- 결측치 처리 및 날짜 데이터 정제

## 5. 분석 및 모델링

### 5-1. 탐색적 데이터 분석 (EDA)

- 수질 지표 간 상관관계 분석  
  - 수온 ↔ DO 강한 음의 상관관계  
  - BOD, COD, TOC, pH ↔ 클로로필-a 양의 상관관계  

- 유량과 녹조의 직접 상관은 낮지만  
  👉 영양염 유입 및 희석에 영향  

---

### 5-2. 특징 엔지니어링 (핵심)

👉 **시차 변수 도입 (가장 중요한 포인트)**

- 수온, 유량, T-N, T-P 등  
- 약 **7일 시차 적용**

📌 이유  
- 녹조는 즉시 발생하지 않고  
👉 **시간 지연 후 증가하는 패턴 존재**  

---

### 5-3. 모델링

#### ① 기존 접근
- Logistic Regression  
- RandomForest  

👉 한계  
- 고위험 구간 예측 성능 부족  
- 데이터 불균형 문제 존재  

---

#### ② 최종 모델 (핵심)

👉 **XGBoost 기반 2단계 모델**

**1단계**
- XGBoost → 고위험 vs 비고위험 분류  

**2단계**
- Logistic Regression → 저위험 / 중위험 분류  

👉 고위험을 먼저 탐지하는 구조 설계  

---

## 6. 모델 성능 및 결과

- 고위험 데이터는 희귀 이벤트 → 단일 모델 한계 존재  
- XGBoost 적용으로 **고위험 탐지 성능 개선**

### 주요 개선 전략

- 임계값 조정 (0.20 ~ 0.25)  
- Recall(재현율) 중심 평가  

👉 일부 오탐 증가  
→ **조기 경보 관점에서는 허용 가능**

---

## 7. 주요 인사이트

- 녹조 발생은 단순 수질 문제가 아니라  
  👉 **시간 지연 기반 생태 현상**

- 강우량 증가 → 부유물질 및 영양염 증가  
→ 비점오염 영향 확인  

- 유량은 직접 영향보다  
👉 **환경 변화 매개 변수 역할**

---
